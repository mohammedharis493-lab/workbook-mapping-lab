# Privacy and release policy

The public repository contains code and intentionally fabricated test data only.

Never commit real financial statements, tax returns, accounting exports, names, PAN/GSTIN, CIN, bank details, addresses, signatures, personal identifiers, confidential client numbers, or de-identified derivatives of actual client records. Replacing names is insufficient to anonymize transaction patterns and rare balances.

Run the public-data gate before every push. This is a conservative screening tool, not a guarantee of anonymisation. Manual review is mandatory.

Keep actual entity folders, import templates, approval rules, and reports strictly local/private. Import into a duplicate/test record before any production change.
